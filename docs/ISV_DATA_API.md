# 数据接口（轨2）：无网页应用上屏规范

小悟双屏（FPC1 黑白 / FPC2 四色）不渲染 HTML，屏幕内容由平台后端出图。
因此**没有网页的桌面 / 服务端应用**（如 codex pulse）要上屏，应走「数据接口」提交轨：
ISV 提供一个 HTTP 端点，按本规范返回 JSON，平台把它实时渲染成墨水屏卡片。

> 两条提交轨二选一即可：
> - **轨1 双屏适配 UI**：提交纯静态网页工程（`index.html`），平台托管并校验；
>   设备显示海报卡（应用名 + 简介 + 二维码），用户扫码在手机打开网页。
> - **轨2 数据接口**（本文）：提交一个数据端点，平台实时取数出卡片，**无需手机扫码**。

## 1. 端点协议

| 项 | 要求 |
|---|---|
| 方法 | `GET` |
| 地址 | `https://`（内网联调可用 `http://`），或平台可访问的地址 |
| 返回 | `application/json`，UTF-8，体积 ≤ 32 KB |
| 鉴权 | 可选。若填写 Token，平台带 `Authorization: Bearer <token>` |
| 双屏 | 平台额外附加查询参数 `?screen=A` 或 `?screen=B`，可据此返回不同内容；忽略则两屏相同 |

平台对同一应用同一屏的取数结果缓存 60 秒；取数失败时回退到最近一次成功样本，
设备仍可出图（卡片底部可自行标注数据时间）。

## 2. 返回 JSON 契约（v1）

```json
{
  "version": 1,
  "title": "API 额度",
  "subtitle": "codex pulse",
  "items": [
    { "label": "剩余额度",   "value": "$42.10", "emphasis": "red" },
    { "label": "到期倒计时", "value": "6 天" },
    { "label": "本月用量",   "value": "68%", "progress": 68 }
  ],
  "footer": "更新于 17:08",
  "qr": "https://example.com/app",
  "refresh_minutes": 15
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `version` | 否 | 契约版本，当前为 `1` |
| `title` | **是** | 卡片标题，≤ 24 字 |
| `subtitle` | 否 | 副标题，≤ 32 字 |
| `items` | **是** | 数据项数组，1 ~ 6 项；每项 `label`（≤12 字）+ `value`（≤20 字） |
| `items[].emphasis` | 否 | `none` / `red` / `yellow`；四色屏用红或黄强调，黑白屏忽略 |
| `items[].progress` | 否 | `0 ~ 100`，在该项下方画进度条（适合额度、完成度） |
| `footer` | 否 | 页脚，≤ 40 字（建议写"更新于 时间"） |
| `qr` | 否 | `http(s)` 绝对地址，右下角生成入口二维码 |
| `refresh_minutes` | 否 | 期望刷新间隔，`1 ~ 1440` 分钟，默认 15 |

### 校验结论

平台保存时会实时抓取并校验，结论分 `pass` / `warn` / `fail`：

- `fail`（如缺 `title`、`items` 为空、端点不可达且无样本）**阻止提交审核**；
- `warn`（如未声明 version、文本超长、端点暂不可达但样本有效）允许提交，但建议修正。

## 3. 开发者操作流程

1. 在「创作者中心 → 应用与内容」创建应用；
2. 在「**数据接口（轨2）**」面板选择目标应用，填写：
   - **数据端点**：返回上述 JSON 的 URL；
   - **Bearer Token**（可选）：端点鉴权用，保存后不回显；
   - **样本 JSON**（可选）：端点暂未上线时用于预览/校验；
3. 点「保存并校验」，查看右侧逐项结论；点「打开数据卡片预览 →」核对双屏出图；
4. 在「我的应用」点「设备出图预览」确认 A/B 屏效果；
5. 校验非 `fail` 后点「提交审核」；运营审核通过后进入「已上线应用」内容库。

## 4. 审核侧

运营在「贡献应用」列表可见每个应用的**提交轨**（数据接口 / 双屏适配 UI）与校验结论，
点「设备出图预览」核对真实出图后再决定通过或驳回。

## 5. 安全与合规

- 端点由 ISV 自行托管，平台会以固定 UA `xiaowu-data-api/1.0` 访问；请勿返回敏感信息；
- 平台限制响应 32 KB、超时 6 秒，避免拖慢渲染；
- 建议端点做速率限制与缓存，避免设备每次刷新都打到上游计费接口；
- 内容须符合平台内容安全规范（不得含违法、有害、色情、暴力、侵权信息）。
